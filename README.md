# VR Digital Hub: AI Creative Boardroom
A next-gen AI-powered decision support system designed to synthesize Gen-Z trends and Corporate strategy.

## Features
- **Triple-Agent System:** Real-time debate between Gen-Z, Corporate, and Creative Director personas.
- **Dynamic Cosmic UI:** Immersive interface with celestial aesthetics.
- **Strategic Synthesis:** Automated 3-step actionable business blueprint generation.

## Tech Stack
- Frontend: Streamlit
- Backend: Groq API (LLaMA 3.1)
- Deployment: Streamlit Cloud

## How to Run
1. Clone the repo.
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `streamlit run main.py`
